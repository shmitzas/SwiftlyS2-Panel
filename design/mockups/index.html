Design
mockups

Static HTML on Bootstrap 5.3 and the panel's own design system — CS2's menu look, with CustomHUD's rules for colour. Every row is shaped like the plugins' real tables (Admins, Ranks and its modules, WeaponSkins, VIPCore); the item catalog is real CS2 data.

Start at the landing page Design system docs/POC.md
View as. The pink bar at the bottom switches between a guest, a VIP player, a player without VIP and the owner. Navigation, staff actions, IP columns and WeaponSkins' locked options follow the roles.
Theme. Pick a preset there, or open the theme editor: a saved theme applies on every page. One accent re-themes the panel; rarity, wear and CS Rating colours stay CS2's own.
Modules. Disable a module on the admin dashboard and its nav entry, pages and profile sections disappear everywhere — the same contract the real module system has.

What is real and what is not

  • Real: table and column names, units (Admins' milliseconds, VIPCore's seconds, Ranks' season ids), status rules, wording and formats copied from the plugins' translations.
  • Real: weapon, skin, agent, sticker, charm, music kit and pin data from ByMykel/CSGO-API (MIT), images from Steam's CDN.
  • Fictional: player names, SteamIDs, statistics, and TEST-NET IP addresses. A player named <script> checks escaping.
  • Not built: PHP, the database layer, Steam sign-in — the mockups are the design half of docs/POC.md.
